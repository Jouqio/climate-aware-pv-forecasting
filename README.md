## Overview

This repository contains the complete research pipeline for the paper:

> **"Deterministic Target Leakage in Photovoltaic Forecasting: Correction,
> Forecastability Characterization, and ENSO-Conditioned Uncertainty for
> the Equatorial Maritime Continent"**

### Core Finding

Standard PV forecasting constructs targets as `Y = f(GHI, T)` then uses
GHI and T as predictors — producing R² = 0.9999 by algebraic identity.
Upon stochastic correction, R² reduces to 0.226, a leakage ratio of
**3.5× (range 2.5–4.7×, CV = 18.0%)** confirmed across 15 parameterisation scenarios.

```python
# Place downloaded CSV in project root:
# POWER_Point_Monthly_20050101_20251231_000d13N_117d50E_UTC.csv
```

### 3. Download NOAA CPC ONI data (⚠ Required before ENSO analysis)

```python
import pandas as pd, requests, io

url = "https://www.cpc.noaa.gov/data/indices/ersst5.nino.mth.91-20.ascii"
response = requests.get(url)
df_raw   = pd.read_csv(io.StringIO(response.text), sep=r'\s+', skiprows=1,
    names=['YR','JAN','FEB','MAR','APR','MAY','JUN',
           'JUL','AUG','SEP','OCT','NOV','DEC'])

# Melt to monthly format and save
months = ['JAN','FEB','MAR','APR','MAY','JUN','JUL','AUG','SEP','OCT','NOV','DEC']
records = []
for _, row in df_raw.iterrows():
    for i, m in enumerate(months):
        records.append({'YEAR': int(row['YR']), 'MONTH': i+1,
                        'ONI_real': float(row[m])})
df_oni = pd.DataFrame(records)
df_oni['DATE'] = pd.to_datetime(
    dict(year=df_oni.YEAR, month=df_oni.MONTH, day=1))
df_oni.to_csv('data/oni_noaa_cpc_real.csv', index=False)
print(f"ONI data: {len(df_oni)} monthly obs, {df_oni.ONI_real.isna().sum()} missing")
```

### 4. Run the complete pipeline

```bash
# Full pipeline (NB01 → NB10): ~60-90 minutes
python3 run_pipeline.py

# Resume from specific notebook:
python3 run_pipeline.py --from 5

# Run single notebook:
python3 run_pipeline.py --only 2
```

## Reproducibility

All stochastic simulations use `np.random.seed(42)`.

For leakage ratio robustness, sensitivity analysis was run across:
- **5 seeds:** 42, 123, 456, 789, 1000
- **3 PR_base values:** 0.75, 0.80, 0.85
- **Result:** mean = 3.47×, CV = 18.0%, range [2.54, 4.74]

To replicate with a different seed:
```python
# In 02_target_reconstruction.py, change:
np.random.seed(42)  # → your seed
```
