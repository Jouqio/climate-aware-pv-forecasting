## Overview

This repository investigates photovoltaic (PV) forecasting under tropical climate variability by integrating:

Deterministic Leakage Correction (DLC)
Climate-aware stochastic PV modeling
ENSO/IOD teleconnection analysis
Explainable Machine Learning (XAI)
Probabilistic forecasting (P10/P50/P90)
